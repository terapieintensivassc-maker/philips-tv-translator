# Dispozitiv țintă

Model confirmat de utilizator: Philips 43PUS7303/12.

Proiectul este configurat cu minSdk 26 (Android 8.0+) și include launcher Android TV. Workflow-ul GitHub Actions construiește un APK debug.

Acest lucru nu confirmă testarea pe televizor. Verifică versiunea exactă Android din meniul Despre și testează redarea site-urilor, permisiunea microfonului și exportul SRT. Unele servicii de streaming pot bloca WebView sau captura audio; aplicația nu ocolește DRM.
